# frigo

Claude Code modları. Bu repo bir eklenti pazarı (marketplace):

```
claude plugin marketplace add elrahir/frigo
claude plugin install bombay@frigo
claude plugin install soz@frigo
```

| Mod | Ne yapar |
|---|---|
| [bombay](plugins/bombay) | Mesaj kutusunun üstünde yaşayan sarı gözlü kara kedi. Çoğunlukla uyur (nefes alır, kulağı seğirir), arada yumakla oynar, mama yer, koşturur; Claude çalışırken turuncu yıldızı kovalar. Masaüstünde vektör, terminalde piksel çizim. Küçük ekranda bant yarıya iner ya da kedi istemin altındaki satıra taşınır (`/bombay big\|mini\|line\|auto`). |
| [soz](plugins/soz) | Türkçe şarkı sözü yazan, eğitimsiz ajan sistemi (deney: Sezen Aksu öykünmesi). Ölçülmüş stil profili, dinamik örnekleme, Verbalized Sampling ile fikir, detay bankası, çok modelli taslaklar, kodla hece/kafiye/redif ve klişe denetimi, "hangisi gerçek?" hakemi, kesme turu. `/soz:sarki-yaz <tema>`. İlk şarkı: [ornekler/001](plugins/soz/ornekler/001). |
