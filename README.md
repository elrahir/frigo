# frigo

Claude Code modları. Bu repo bir eklenti pazarı (marketplace):

```
claude plugin marketplace add elrahir/frigo
claude plugin install bombay@frigo
```

| Mod | Ne yapar |
|---|---|
| [bombay](plugins/bombay) | Mesaj kutusunun üstünde yaşayan sarı gözlü kara kedi. Çoğunlukla uyur (nefes alır, kulağı seğirir), arada yumakla oynar, mama yer, koşturur; Claude çalışırken turuncu yıldızı kovalar. Masaüstünde vektör, terminalde piksel çizim. |
